# 기능 명세 · MVP 우선순위

---

## 우선순위 정의

| 우선순위 | 정의 |
|---|---|
| P0 | 3주 시연을 위한 필수 기능. 다른 기능보다 안정화를 우선 |
| P1 | P0 완료 시 추가, 업무 블럭 연동이 1순위 |
| P2 | 3주 과제 이후 확장 대상으로 남기는 기능 |

---

## P0 기능 정의

| ID | 기능 | 필수 동작 | 확인 기준 | 구현 |
|---|---|---|---|---|
| F01 | 게스트 참여 | 이름·초대 코드 검증, 프로젝트 멤버십 생성 | 잘못된 코드는 거부 | 완료 (AC01) |
| F02 | 보드 관리 | 프로젝트별 보드 복수 생성·전환 | 다른 보드 내용이 섞이지 않음 | 완료 (AC02) |
| F03 | 펜 | 마우스 이동 중 부분 좌표 공유, 마우스업 후 저장 | 타 PC에 그리는 중 선 표시 | 완료 (AC03) |
| F04 | 도형 | 사각형·원 기본 생성·선택·이동·삭제 | 다른 사용자에게 변경 반영 | 완료 (AC04) |
| F05 | 커서 | 보드 참여자의 이름·좌표·색상 공유 | 접속자별 구분 가능 | 완료 (AC05) |
| F06 | 잠금 | 편집 시작 시 객체 선점, 해제, TTL·연결 종료 복구 | 동시 수정 거부 | 완료 (AC06·AC07) |
| F07 | 이미지 | PNG/JPG/WEBP 10MB 이하, 버튼·드래그·붙여넣기 | 허용 형식과 크기 검사 | 완료 (AC08~AC10) |
| F08 | 외부 영상 | URL 검증 후 허용 서비스 임베드 | 보드 내 재생 | 완료 (AC11) |
| F09 | 영구 저장 | 편집 확정 시 DB 저장, 재접속 시 최신 상태 로드 | 마지막 저장 상태 복원 | 완료 (AC12·AC13) |
| F10 | 권한 | 관리자·편집자·열람자, 서버 권한 검사 | 열람자 수정 불가 | 완료 (AC14) |

P0 는 모두 구현되어 개발 PC 에서 검사를 통과했습니다. 학교 PC 4대 접속(AC15)만 남아 있습니다.

## P1/P2 기능

| 단계 | 기능 | 구현 |
|---|---|---|
| P1 | 여러 보드에서 동일 원본 업무 참조(상태·담당자·마감일), 표시 블럭만 삭제 | 완료 (AC16·AC17) |
| P1 | 관계 라벨·화살표 연결선 | 완료 (AC18) |
| P1 | 여러 객체 선택·동시 이동 및 격자 맞춤 | 완료 (AC19) |
| P1 | 초대 링크/참여 코드 편의 기능, 모의 이메일 초대 안내 | 초대 링크와 관리자 화면의 코드 발급·취소·인원 제한은 완료 (AC20). 모의 이메일 안내는 만들지 않음 |
| P2 | 고급 체크리스트, 댓글, 원본 업무의 첨부파일 | 미구현 |
| P2 | 스프레드시트급 테이블, 흐름도 자동 정렬, 고급 일정·칸반 | 미구현. 상태별 세 열로 보는 간단한 현황판만 17단계에서 구현 |

## 계획에 없었지만 구현한 것

시연과 사용 편의를 위해 단계별로 더한 기능입니다. 모두 P1 수준으로 다룹니다.

| 기능 | 내용 | 단계 |
|---|---|---|
| 소개 홈페이지와 작업실 | 처음 열면 소개, 입장하면 같은 자리가 보드·업무 현황판·참여자·초대 관리 화면으로 바뀜 | 10 |
| 크기 조절 | 모서리 핸들로 도형·이미지·영상·업무 블럭·메모 크기 변경 (AC21) | 9 |
| 메모·텍스트 | 글을 적는 메모와 배경 없는 텍스트, 글자 크기 조절 (AC22) | 11·16 |
| 보드 이름 변경·삭제 | 작업실에서 변경, 보드 안 참여자에게 알림 (AC23) | 11 |
| 실행 취소·다시 실행 | 내가 한 작업만 되돌리고 다시 적용. 다른 사람이 이후에 고친 객체는 건드리지 않음 (AC24) | 12·16 |
| 복제·PNG 내보내기 | 선택 객체 복제, 보드 전체를 그림으로 저장 (AC25) | 12 |
| 시연 도구 | 예시 보드 채우기, 시연 초기화, 화면 캡처, 4인 자동 리허설, 서버·접속 PC 점검 | 9·13·14·15 |
| 새로고침 복원 | 새로고침해도 보던 보드와 위치로 복귀 | 15 |
| 업로드 정리 | 어느 보드에서도 쓰지 않는 이미지 파일 정리 스크립트 | 16 |
| 업무 현황판 | 작업실에서 공유 업무를 할 일·진행 중·완료 세 열로 보고, 카드를 끌어 상태를 바꾸고, 카드를 눌러 고치거나 새로 만듦. 보드의 업무 블럭과 서로 바로 반영 (AC26) | 17 |
| 마감 표시 | 마감이 지났거나 3일 안으로 다가온 업무를 현황판 카드와 보드의 업무 블럭에 색으로 표시. 완료한 업무는 표시하지 않음 | 17 |

이후에 더할 기능(참여자 따라가기, 실시간 이벤트 요청 제한, 업무 체크리스트)은 [역할과 일정](10-wbs-timeline.md)의 "이후 단계 계획"에 있습니다.

## 범위 정책

- P0가 2주 종료 시점에 불완전하면 P1 신규 개발을 중단.
- P2는 프로덕션 기능으로 설명하지 않음.
- 사용자 커서·미완성 획은 임시 정보이므로 DB에 쓰지 않음.
- 미저장 작업은 재연결 시 **복원 보장하지 않음**.
- 12장·10장 PPT 의 화면은 기획 목업입니다. 실제 구현 화면은 `assets/screenshots/` 와 14장 PPT 의 4·9·10·11장에 있습니다.
