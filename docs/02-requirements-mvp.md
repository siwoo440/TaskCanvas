### 시각화 데이터·출처 구분

- **프로젝트 DB 업무 데이터:** `tasks`의 상태·담당자·마감과 `task_items` 체크리스트를 차트 및 KPI로 집계.
- **가져온 데이터:** CSV·JSON 파일 또는 공공데이터포털 API 결과를 **별도 데이터셋**으로 DB에 저장하고, 원본 링크·제공기관·수집 시각을 기록.
- **차트 종류:** 원형(파이·도넛)은 범주별 비율, 막대는 항목별 건수·합계, 선은 날짜별 추이, 표는 원본 조회. Chart.js 도입 제안.
- **정확성:** 업무 상태 변경 이력이 없는 과거 자료에서 완료 시각을 추정하지 않음. 표본·가상 데이터는 '예시'로 명시. 데이터 소스별 단위를 확인해 임의로 합산하지 않음.
- **보안:** 회원 비밀번호는 `password_hash()` 기반으로 보호, 외부 API 서비스키는 서버만 보유, 다운로드/업로드 입력·행 수·용량 제한, DB 접근 권한 검사. 공공데이터 API 호출은 사전에 허용한 제공처만 사용.
- **시연 대체 경로:** 학교 LAN에서 외부 API 접근이 제한되면 **DB에 기존 저장된 공공데이터 또는 샘플 CSV**를 이용하여 저장·시각화 단계를 재현.
