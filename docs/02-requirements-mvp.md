# 기능 명세 · MVP 우선순위

---

## 우선순위 정의

| 우선순위 | 정의 |
|---|---|
| P0 | 3주 시연을 위한 필수 기능. 다른 기능보다 안정화를 우선 |
| P1 | P0 완료 시 추가, 업무 블럭 연동이 1순위 |
| P2 | 3주 과제 이후 확장 대상으로 남기는 기능 |

---

## P0 기능 정의

| ID | 기능 | 필수 동작 | 확인 기준 |
|---|---|---|---|
| F01 | 게스트 참여 | 이름·초대 코드 검증, 프로젝트 멤버십 생성 | 잘못된 코드는 거부 |
| F02 | 보드 관리 | 프로젝트별 보드 복수 생성·전환 | 다른 보드 내용이 섞이지 않음 |
| F03 | 펜 | 마우스 이동 중 부분 좌표 공유, 마우스업 후 저장 | 타 PC에 그리는 중 선 표시 |
| F04 | 도형 | 사각형·원 기본 생성·선택·이동·삭제 | 다른 사용자에게 변경 반영 |
| F05 | 커서 | 보드 참여자의 이름·좌표·색상 공유 | 접속자별 구분 가능 |
| F06 | 잠금 | 편집 시작 시 객체 선점, 해제, TTL·연결 종료 복구 | 동시 수정 거부 |
| F07 | 이미지 | PNG/JPG/WEBP 10MB 이하, 버튼·드래그·붙여넣기 | 허용 형식과 크기 검사 |
| F08 | 외부 영상 | URL 검증 후 허용 서비스 임베드 | 보드 내 재생 |
| F09 | 영구 저장 | 편집 확정 시 DB 저장, 재접속 시 최신 상태 로드 | 마지막 저장 상태 복원 |
| F10 | 권한 | 관리자·편집자·열람자, 서버 권한 검사 | 열람자 수정 불가 |

---

## P1/P2 기능

| 단계 | 기능 |
|---|---|
| P1 | 여러 보드에서 동일 원본 업무 참조(상태·담당자·마감일), 표시 블럭만 삭제 |
| P1 | 관계 라벨·화살표 연결선 |
| P1 | 여러 객체 선택·동시 이동 및 격자 맞춤 |
| P1 | 초대 링크/참여 코드 편의 기능, 모의 이메일 초대 안내 |
| P2 | 고급 체크리스트, 댓글, 원본 업무의 첨부파일 |
| P2 | 스프레드시트급 테이블, 흐름도 자동 정렬, 고급 일정·칸반 |

---

## 범위 정책

- P0가 2주 종료 시점에 불완전하면 P1 신규 개발을 중단.
- P2는 프로덕션 기능으로 설명하지 않음.
- 사용자 커서·미완성 획은 임시 정보이므로 DB에 쓰지 않음.
- 미저장 작업은 재연결 시 **복원 보장하지 않음**.
- 첨부 PPT 화면은 기획 목업이며 실제 구현 화면이 아님.
