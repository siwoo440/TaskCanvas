## 4차 결정 반영을 위한 14장 개정 계획

- 1~2장: 4명·3주·학교 PC LAN, 게스트 사용 구조 명시.
- 3장: 가입/로그인 설명 대신 초대 코드·게스트 입장.
- 4장: UI 콘셉트 표시, 접속 인원 4명으로 통일.
- 5장: PNG/JPG/WEBP, 파일당 10MB, 외부 영상 임베드.
- 6장: 연결 종료·잠금 만료·미저장 변경 복원 규칙.
- 7장: PHP 게스트 세션 + Node.js 단기 티켓·DB.
- 8~11장: 본인 기획·통합 역할 확정, 나머지 일부 모집, WBS 산출물·API 인계 명시.
- 12장: 1주 2인 / 2주 4인 / 3주 시연 목표와 P1 중단 기준.
- **13장 신규:** 기능 수용 기준(AC01~AC17 중 주요 P0).
- **14장 신규:** 학교 PC·네트워크·3주 범위 위험과 대응.

**현재 패키지는 기존 PPT 원본을 수정하지 않았으며, 위 개정 내용은 후속 PPT 작업 항목입니다.**
