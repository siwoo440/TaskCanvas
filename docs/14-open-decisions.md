# 개발 전 미확정 결정 사항

---

## 결정 필요 항목

| 항목 | 상태 | 제안 |
|---|---|---|
| 최초 관리자 게스트 지정 | **결정(9단계)** | `create-project.php` 가 관리자 초대 코드를 한 번 출력. 그 코드로 입장한 사람이 관리자가 되어 화면에서 나머지 코드를 발급 |
| 초대 코드 만료·재사용 | **결정(9·16단계)** | 유효 기간 1~30일(기본 7일), 만료 전까지 여러 명이 재사용 가능, 관리자가 언제든 취소. 16단계에서 선택 사항으로 인원 제한(1~100명)을 추가. 새로 입장하는 사람만 세고, 이미 입장한 이름의 재입장은 세지 않음 |
| 학교 PC Node/방화벽/포트 | 실환경 미확인 | 첫날 `scripts\check-env.bat` 으로 점검하고 다른 PC 에서 접속 확인 ([배포 가이드](15-deployment-school-pc.md)) |
| 영상 허용 서비스 | **결정(5단계)** | YouTube 와 Vimeo. 서버가 ID 형식을 검사해 임베드 URL 생성 |
| 최초 보드 선택 | **결정(3단계)** | 입장 후 보드 목록 화면에서 직접 선택 |
| 이미지 삭제·참조 수명 | **결정(16단계)** | 객체를 지워도 파일은 남김(지운 사람이 실행 취소로 되살릴 수 있어야 함). 어느 보드에서도 쓰지 않는 이미지는 `clean-uploads.php` 로 아무도 편집하지 않을 때 정리. 즉시 자동 삭제는 하지 않음 |
| 객체 잠금 TTL | **결정(4단계)** | 30초(`LOCK_TTL_MS`), 미리보기·확정마다 연장, 5초 주기 만료 검사 |
| 지연 정량 기준 | **제안(14단계)** | 미리보기(펜·이동) 전달 중앙값 150ms 이하, 확정 저장 응답 중앙값 500ms 이하. `npm run rehearsal` 이 재서 판정. 개발 PC 1대 안에서는 각각 약 1ms·3~6ms(LAN 구간 제외). 학교 LAN 에서의 값은 아직 재지 못함. 접속 PC 의 접속 점검 화면(`/check.html`)이 PC 별 왕복 시간을 보여 줌 |
| 팀원 실명과 GitHub 권한 | 일부 확정 | 확정 후만 역할 배정·쓰기 권한 부여 |
| 실제 PHP/Node 버전 | 학교 PC 확인 전 | PHP 8.0 이상·Node 18 이상이면 동작(개발 PC 는 8.2·24). `scripts\check-env.bat` 이 버전과 확장을 확인 |

---

## 이번 버전에서 확정된 것

게스트 입장, PC 4대 동시 편집, 펜 즉시 공유, 작업 확정 저장, 마지막 저장 상태 복원, 객체 선점 잠금, 10MB 이미지 제한, 영상 외부 URL, 본인의 기획·통합 역할, P1 업무 원본 연동 우선순위는 **확정**되었습니다.
