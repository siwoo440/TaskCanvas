# 개발 전 미확정 결정 사항

---

## 결정 필요 항목

| 항목 | 상태 | 제안 |
|---|---|---|
| 최초 관리자 게스트 지정 | 미정 | 관리자 전용 초대 코드 또는 사전 등록 |
| 초대 코드 만료·재사용 | 미정 | 프로젝트별 만료·발급 횟수 제한 |
| 학교 PC Node/방화벽/포트 | 실환경 미확인 | 첫날 실제 PC 확인 |
| 영상 허용 서비스 | 미정 | YouTube 우선, 허용 도메인 방식 |
| 최초 보드 선택 | 미정 | 마지막 보드 또는 프로젝트 기본 보드 |
| 이미지 삭제·참조 수명 | 미정 | 마지막 참조 제거 시 서버 정책에 따라 정리 |
| 객체 잠금 TTL | 미정 | 짧은 TTL과 주기적 연장 후 테스트 |
| 지연 정량 기준 | 미정 | 시연에서 눈에 띄는 지연 없이 동작 |
| 팀원 실명과 GitHub 권한 | 일부 확정 | 확정 후만 역할 배정·쓰기 권한 부여 |
| 실제 PHP/Node 버전 | 학교 PC 확인 전 | XAMPP/MariaDB·Node LTS 호환성 검증 |

## 이번 버전에서 확정된 것

게스트 입장, PC 4대 동시 편집, 펜 즉시 공유, 작업 확정 저장, 마지막 저장 상태 복원, 객체 선점 잠금, 10MB 이미지 제한, 영상 외부 URL, 본인의 기획·통합 역할, P1 업무 원본 연동 우선순위는 **확정**되었습니다.
