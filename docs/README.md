# TaskCanvas 문서 목차

> 기획·설계 문서이며, 06·07·08·09·11·12·14·15 번은 구현하면서 실제 동작에 맞춰 갱신했습니다(각 문서의 "구현 상태" 표기 참고). 13 번은 발표 자료 14장 개정에 맞춰 다시 썼고 16 번은 시연용으로 새로 썼습니다. 00·02~05 번은 16단계에서 구현 기준으로 다시 썼습니다. 그 뒤에 더하는 기능의 계획은 10 번의 "이후 단계 계획"에 있습니다. **26일차 회원가입·로그인·로그아웃 API와 화면은 구현**했으며, 27일차 회원 권한·작업실 초대·실시간 세션 연계도 구현했으며, 28일차 SQL 통계와 29일차 KPI·차트·업무 표 분석 화면도 구현했습니다. 30일차 CSV·JSON 업로드·원본 미리보기도 구현했습니다. 31일차 컬럼 매핑·전체 검증·확정 데이터셋 저장도 구현했습니다. 공공데이터 가져오기는 후속 계획입니다. **2026-10-20 최신 일정에서는 E01~E17을 포함한 33~78일차가 미구현·계획**이며, [재배치 로드맵](30-roadmap-reordered.md)이 과거 개발 일차보다 우선합니다. 01 번(질문과 결정 기록)과 10 번의 계획 표는 기획 당시 기록 그대로 두고, 구현 후 달라진 점만 끝에 덧붙였습니다. **요구사항의 최신 확정 결정은 1~4차 질의 결과와 4차 최종 제약입니다.**
