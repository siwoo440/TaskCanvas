# TaskCanvas 문서 목차

> 기획·설계 문서이며, 06·07·08·09·11·12·14·15 번은 구현하면서 실제 동작에 맞춰 갱신했습니다(각 문서의 "구현 상태" 표기 참고). 13 번은 발표 자료 14장 개정에 맞춰 다시 썼고 16 번은 시연용으로 새로 썼습니다. 00·02~05 번은 16단계에서 구현 기준으로 다시 썼습니다. 그 뒤에 더하는 기능의 계획은 10 번의 "이후 단계 계획"에 있습니다. **26일차 회원가입·로그인·로그아웃 API와 화면은 구현**했으며, 27일차 회원 권한·작업실 초대·실시간 세션 연계도 구현했으며, 데이터 시각화·파일/공공데이터 가져오기는 계속 계획 단계입니다. **2026-10-18 추가한 E01~E14 제품 기능도 모두 미구현·계획**이며, 36~52일차에 순차 개발하도록 별도 백로그를 추가했습니다. 01 번(질문과 결정 기록)과 10 번의 계획 표는 기획 당시 기록 그대로 두고, 구현 후 달라진 점만 끝에 덧붙였습니다. **요구사항의 최신 확정 결정은 1~4차 질의 결과와 4차 최종 제약입니다.**
