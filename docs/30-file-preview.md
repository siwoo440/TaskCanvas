# 30일차 — CSV·JSON 업로드와 원본 미리보기

2026-10-20 최신 일정의 30일차 범위다. 작업실에서 파일을 업로드하고 구조·전체 행 수·첫 20행을 확인한다. 업로드한 바이트는 세션 초안으로 임시 보관하며 확정 데이터셋 저장 기능은 제공하지 않는다.

---
## 1. 사용 방법

1. 작업실에서 **데이터 관리**를 연다.
2. **CSV 또는 JSON 파일**을 선택한다. CSV 인코딩은 **UTF-8/BOM** 또는 **CP949**를 지정한다. JSON은 UTF-8만 지원한다.
3. **파일 업로드**를 누른다. CSV와 루트 JSON 객체 배열은 바로 표를 표시한다.
4. 중첩 JSON은 **발견한 JSON 배열**에서 후보를 선택하거나 **JSON 배열 경로**를 직접 입력하고 **원본 다시 읽기**를 누른다. 예: `/data/items`. 루트 배열의 경로는 빈 문자열이다.
5. 파일명·형식·인코딩·전체 행 수·만료 시각과 첫 20행을 확인한다. 파일의 데이터가 25행이면 전체 25행으로 표시하지만 표는 20행까지 출력한다.

파일을 바꾸면 이전 토큰·표·경로를 폐기하고 다시 업로드해야 한다. 인코딩·경로만 바꾸면 같은 초안의 원본을 다시 읽는다. 실패한 요청 뒤 이전 표를 성공 결과처럼 남기지 않는다. 작업실 복귀·전환·로그아웃·계정 변경 때 파일 입력·원문·토큰·늦은 응답을 폐기한다.

---
## 2. 지원 형식과 제한

| 항목 | 기준 |
| --- | --- |
| 파일 | CSV·JSON, 1~5,242,880바이트(5MiB) |
| 데이터 | 1~10,000행, 원본 1~50컬럼 |
| CSV | 쉼표 구분·첫 레코드 헤더·UTF-8/BOM 또는 명시적 CP949 |
| CSV 인용 | 인용부호 안 쉼표·줄바꿈·이중 인용부호 지원 |
| JSON | UTF-8 객체 배열, JSON Pointer 배열 경로, 중첩 객체 5단계 펼치기 |
| JSON 보호 | 문서 깊이16·전체 요소600,000 한도, decoded 중복 키 거부, 숫자 토큰 원문 유지 |
| 미리보기 | 첫20행, 모든 원본 행에서 발견한 컬럼 합집합 |
| 행 번호 | 헤더를 제외한 데이터 레코드의 1부터 시작하는 번호 |

JSON Pointer는 `/`를 `~1`, `~`를 `~0`으로 표현한다. JSON 배열 셀·행 객체가 아닌 값·CSV 열 수 불일치는 해당 원본 행 구조 안내에 표시한다. 빈/중복 헤더, 손상 인코딩, 미완성 인용부호·JSON 구문, 없는 배열 경로는 명확한 오류로 거부한다. HTML처럼 보이는 값도 텍스트로 출력하며 실행하지 않는다.

표본 CSV:

```csv
이름,분류
한글,검증
```

표본 JSON(경로 `/data/items`):

```json
{"data":{"items":[{"이름":"한글","금액":0.3}]}}
```

## 3. 권한과 초안 수명

- 관리자·편집자만 업로드와 초안 재해석이 가능하다. 열람자는 데이터 관리 화면의 권한 안내를 볼 수 있다.
- 회원 연결 게스트는 유효한 회원 쿠키와 회원 세션에 종속된 게스트 쿠키가 모두 필요하다. 비회원 게스트는 기존 작업실 역할을 따른다.
- 초안은 **현재 게스트 세션과 작업실**에 결합한다. 같은 회원이라도 다른 세션의 초안 토큰은 사용할 수 없다.
- 초안은 업로드 시점부터 **고정15분**, 세션당 활성3개·작업실당10개다. 화면에서 닫아도 보관 초안은 만료 전까지 한도에 포함된다.
- DB에는 토큰 해시만 보관한다. 원본은 공개 파일 경로에 영구 저장하지 않고 최대64KiB 조각으로 보관한다. 복원 시 조각 순서·크기·SHA-256을 확인한다.
- 업로드 시 해당 작업실의 만료 초안을 제한적으로 정리한다. CLI `php apps/php-api/bin/cleanup-imports.php`는 기본 dry-run, `--apply`를 붙일 때만 만료 초안을 최대100개 삭제한다. DB 장애는 비정상 종료 코드1로 전달한다.

초안이 만료되거나 정리된 경우 파일을 다시 선택해 업로드한다. 1MiB DB 패킷에서 5MiB 원본은64KiB 조각80개로 저장·복원된다. 서버 전역 MariaDB 설정은 변경하지 않는다. `scripts/start-dev.bat`는 기존10MB 이미지와 파일 전송을 지원하도록 PHP 프로세스의 `upload_max_filesize`·`post_max_size`를12M으로 지정한다.

## 4. API 계약

두 경로 모두 `X-TaskCanvas: 1`, 유효한 세션, 해당 작업실의 편집자 이상 역할이 필요하다. 오류·성공 모두 기존 no-store 응답 규칙을 사용한다.

| 경로 | 요청 | 응답 |
| --- | --- | --- |
| POST `/api/projects/{id}/imports/upload` | multipart `file`, `encoding=UTF-8/CP949` | 최초 `draft_token`과 원본 메타데이터 |
| POST `/api/projects/{id}/imports/preview` | JSON `draft_token`, 선택 `encoding`·`json_path` | 원본 재해석 결과. 토큰을 다시 노출하지 않음 |

공개 메타데이터는 `file_name`, `format`, 적용된 `encoding`·`json_path`, `expires_at`, `requires_path`, `paths`, `row_count`, `columns`, `rows`, `validation_revision`이다. 경로 선택 대기는 `requires_path=true`·`row_count=null`이다. `columns`는 source_id·path·label, `rows`는 source_row·values·errors를 제공한다. 회원/게스트 세션 ID·원본 전체·토큰 해시는 응답하지 않는다.

주요 오류: 400(입력 형식),401/403(인증·역할),404 DRAFT_NOT_FOUND(없거나 다른 세션의 초안),409 DRAFT_CORRUPT(원본 손상),410 DRAFT_EXPIRED,413 FILE_TOO_LARGE,415 INVALID_FILE,429 IMPORT_LIMIT(초안 한도). 경로·인코딩 오류는 기존 초안의 원본을 덮어쓰지 않는다.
