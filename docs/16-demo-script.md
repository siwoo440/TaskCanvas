# 시연 대본 (한 장)

PC 4대로 약 8분 동안 보여 주는 순서입니다. 서버 준비와 문제 해결은 [배포·시연 가이드](15-deployment-school-pc.md), 판정 기준은 [수용 테스트](11-acceptance-tests.md)를 따릅니다.

> **상태:** 1~10번 장면은 리허설 스크립트(`npm run rehearsal`)가 한 PC 안에서 브라우저 네 개로 처음부터 끝까지 실행해 통과했습니다(18단계에도 같은 13개 항목 통과). 실제 PC 4대를 LAN 으로 연결해서는 아직 해 보지 않았으므로(AC15 미실행) 발표 전에 같은 순서로 한 번 리허설합니다.

---

## 자리 배치

| PC | 사람 | 입장 코드 | 맡은 장면 |
|---|---|---|---|
| PC1 (서버) | A | 관리자 | 진행·펜·실행 취소·PNG, 발표 자료 넘기기 |
| PC2 | B | 편집자 | 잠금(메모 잡고 있기), 보드 전환 |
| PC3 | C | 편집자 | 이미지 올리기 |
| PC4 | D | 편집자 → 마지막에 열람자 | 영상 추가, 업무 현황판, 열람자 화면 |

이름은 각자 실제 이름을 입력합니다. 화면의 커서·잠금 이름표에 그 이름이 그대로 보입니다.

## 시작 30분 전

서버 PC

- [ ] `scripts\check-env.bat` → `[실패]` 항목이 없어야 함(PHP·Node·DB·포트·방화벽). 맨 아래에 접속 PC 가 열 주소가 나옴
- [ ] `scripts\start-dev.bat` 실행 → `http://localhost:8080/api/health` 가 `"db":true`
- [ ] (선택) `cd apps/realtime` 에서 `npm run test:acceptance`, `npm run rehearsal` 로 점검 — 반드시 초기화 **전에**
- [ ] `scripts\reset-demo.bat --seed` → 예시가 채워진 "시연 프로젝트"와 초대 코드 3개 출력. 코드는 종이에 적어 전달(저장소·메신저에 남기지 않음)

접속 PC 3대

- [ ] Chrome 에서 `http://<서버 IP>:8080/check.html` 을 열어 모든 항목이 통과인지 확인. "외부 영상"이 주의로 나오면 5번의 영상은 건너뜀
- [ ] PC3 바탕화면에 PNG 파일(10MB 이하) 하나, PC4 에 YouTube 주소 하나 준비
- [ ] 브라우저 확대 100%, 전체 화면

## 진행 순서

| # | 시간 | 누가 | 조작 | 한 줄 설명 | 확인 |
|---|---|---|---|---|---|
| 1 | 0:00 | 전원 | 소개 페이지 → **입장하기** → 이름 + 초대 코드 | "회원가입 없이 이름과 코드만으로 들어옵니다." | 작업실 참여자 4명 (AC01) |
| 2 | 0:40 | 전원 | 작업실에서 **기획 보드** 열기 | "예시 내용은 스크립트로 미리 채워 둔 것입니다." | 상단 참여자 4명, 서로의 커서 (AC05) |
| 3 | 1:20 | A | 펜(P)으로 천천히 선 긋기 | "다 그린 뒤가 아니라 그리는 중에 보입니다." | 다른 3대에 선이 따라 그려짐 (AC03) |
| 4 | 2:00 | B → A | 둘 다 선택 도구(V). B 가 파란 메모를 누른 채 끌고 **멈춤**, A 가 같은 메모 클릭 | "먼저 잡은 사람만 고칠 수 있습니다." | A 화면에 "B 님이 편집 중" 안내와 점선 테두리, B 가 놓으면 풀림 (AC06·AC07) |
| 5 | 2:50 | C, D | C 는 PNG 를 캔버스의 **빈 곳**으로 드래그. D 는 Space+드래그로 빈 곳을 화면 가운데로 옮긴 뒤 ▶ 버튼에 YouTube 주소 입력 | "이미지는 서버가 형식과 10MB 를 검사합니다." | 4대 모두에 이미지·영상 표시 (AC08·AC10·AC11) |
| 6 | 3:50 | B → A | B 는 상단 보드 전환에서 **개발 보드** 선택, A 는 기획 보드의 "로그인 화면 디자인" 블럭을 골라 오른쪽 패널에서 상태를 **완료**로 저장 | "같은 업무를 두 보드가 함께 봅니다." | B 의 개발 보드 블럭도 완료로 바뀜 (AC16) |
| 7 | 4:40 | 전원 | B 는 기획 보드로 복귀. 모두 **F5** | "놓는 순간 저장되므로 새로고침해도 보던 그대로입니다." | 보던 보드와 위치로 돌아오고 3~6번 결과가 그대로 (AC12·AC13) |
| 8 | 5:20 | A | 사각형(R) 하나 그리고 Ctrl+Z, 이어서 **⬇ PNG** | "되돌리기는 내가 한 작업만, 결과는 그림으로 저장됩니다." | 사각형이 4대에서 사라짐, PNG 파일 저장 (AC24·AC25) |
| 9 | 6:10 | D | **‹ 작업실** → 업무 현황판에서 "실시간 서버 방 구현" 카드를 **진행 중** 열로 끌어 놓기 | "업무는 작업실에서 한눈에 보고 끌어서 바꿉니다. 마감이 가까우면 색으로 알려 줍니다." | 다른 3대의 기획 보드에서 그 업무 블럭이 진행 중으로 바뀜 (AC26) |
| 10 | 6:50 | D | 작업실에서 **나가기** → 다른 이름 + 열람자 코드로 다시 입장 → 기획 보드 | "열람자는 볼 수만 있고, 서버도 따로 막습니다." | 도구가 꺼져 있고 화면 이동만 됨 (AC14) |
| 11 | 7:30 | A | 발표 자료 13·14장으로 전환 | 테스트 결과와 남은 위험 설명 | — |

- 1번: 초대 코드 없이 시작하는 방법도 있다는 것을 한 문장으로 덧붙입니다. "소개 화면의 새 작업실 만들기로 이름만 정해 내 작업실을 만들 수도 있습니다." 시연은 예시가 채워진 프로젝트로 진행합니다.
- 5번: ▶ 버튼으로 넣은 영상은 **화면 가운데**에 생깁니다. 그대로 넣으면 예시 내용 위에 겹쳐 6번의 업무 블럭을 누르기 어려우므로 D 는 먼저 화면을 옮깁니다. 겹쳤다면 영상 위쪽 제목 막대를 잡아 빈 곳으로 옮깁니다.
- 7번: 새로고침하면 작업실을 거치지 않고 보던 보드로, 보던 위치·배율 그대로 돌아옵니다. 작업실에서 새로고침하면 작업실에 그대로 있습니다.
- 8번: 되돌린 직후 Ctrl+Y 를 누르면 사각형이 다시 나타납니다(다시 실행). 시간이 남으면 함께 보여 줍니다.
- 9번: 현황판 오른쪽 위가 "실시간 연결됨"일 때 끌 수 있습니다. "로그인 화면 디자인" 카드는 6번에서 바꾼 대로 완료 열에 있습니다. 시간이 남으면 카드를 눌러 마감일을 고치거나 **새 업무**로 업무를 하나 만들어 보입니다.
- 10번: D 는 **처음과 다른 이름**을 써야 합니다. 열람자 코드로 편집자였던 이름을 쓰면 "더 높은 권한의 참여자가 쓰고 있습니다" 안내와 함께 입장이 거부됩니다.

## 막혔을 때

| 상황 | 바로 할 일 |
|---|---|
| 접속 PC 에서 페이지가 안 열림 | 서버 IP 와 방화벽 8080 확인. 안 되면 서버 PC 한 대에서 Chrome 과 Edge 두 창으로 1~4번·7~10번만 진행 |
| 상단에 `재접속 중` | 실시간 서버 창이 닫혔는지 확인하고 `scripts\start-dev.bat` 다시 실행 |
| "실시간 서버에 연결하지 못했습니다" 안내 | 그 PC 에서 주소 끝에 `/check.html` 을 붙여 열면 어느 단계에서 막히는지 나옴. 대개 실시간 서버 창이 꺼졌거나 방화벽 3001 |
| 영상이 검게 보임 | 학교 네트워크 차단. "영상은 주소만 저장하고 재생은 외부 서비스가 합니다"라고 설명하고 넘어감 |
| 초대 코드 거부 | A 가 작업실의 **초대 코드 관리**에서 새로 발급 |
| 현황판의 카드가 끌리지 않음 | 오른쪽 위 표시가 "연결 안 됨"이면 실시간 서버 창을 확인하고 F5. 급하면 보드에서 업무 블럭을 골라 오른쪽 패널로 상태를 바꿈 |
| 한 PC 가 늦게 따라옴 | 그 PC 에서 F5. 마지막 저장 상태로 돌아오는 것 자체가 7번의 설명 |

## 끝난 뒤

- A 가 작업실의 **초대 코드 관리**에서 남은 코드를 모두 취소합니다.
- 서버 PC 의 두 서버 창을 닫습니다. 다음 리허설 전에는 `scripts\reset-demo.bat --seed` 로 다시 시작합니다.
