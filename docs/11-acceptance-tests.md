## P0 테스트 시나리오

| ID | 검증 대상 | 통과 조건 | 상태 |
|---|---|---|---|
| AC01 | 게스트 참여 | 유효 코드 입장, 잘못된 코드 거부 | 통과(자동) |
| AC02 | 보드 분리 | 보드 A와 B의 객체가 섞이지 않음 | 통과(자동) |
| AC03 | 펜 | 그리는 **중** 다른 화면에 표시 | 통과(자동) |
| AC04 | 도형 | 생성·이동·삭제가 다른 PC에 반영 | 통과(자동) |
| AC05 | 커서 | 사용자별 이름·색상·위치 확인 | 통과(자동) |
| AC06 | 잠금 | A의 잠긴 객체에 B의 수정 요청 차단 | 통과(자동) |
| AC07 | 잠금 해제 | 완료·이탈·만료 시 해제 | 통과(자동) |
| AC08 | 이미지 | PNG·JPG·WEBP, 파일 10MB 이하 업로드 성공 | 통과(자동) |
| AC09 | 업로드 거부 | 허용되지 않은 파일/10MB 초과 거부 | 통과(자동) |
| AC10 | 추가 방식 | 선택·드래그·붙여넣기 작동 | 통과(브라우저 수동, 2026-10-08) |
| AC11 | 영상 | 허용 URL을 iframe/플레이어로 재생 | URL 변환 통과(자동), iframe 표시 통과(브라우저 수동) |
| AC12 | 자동 저장 | 작업 확정 뒤 새로고침 후 내용 복원 | 통과(자동) |
| AC13 | 재접속 | 마지막 확정 저장 상태로 복원 | 통과(자동) |
| AC14 | 접근 권한 | 열람자의 변경 이벤트를 서버에서 거부 | 통과(자동) |
| AC15 | 실제 LAN | 학교 PC에 다른 3대 PC 접속 | 미실행(학교 PC 필요) |

**자동 검사 실행:** `cd apps/realtime && npm run test:acceptance` — PHP 8081·실시간 3002 포트로 임시 서버를 띄워 위 항목을 검사하고 결과 표를 출력합니다(2026-10-08 개발 PC에서 19 통과, 0 실패, 수동 2 — P1 의 AC16~AC21 포함). 브라우저 수동 항목은 [apps/frontend/README.md](../apps/frontend/README.md)의 조작 표를 기준으로 확인합니다.

## 최종 시연 흐름

1. 학교 PC에서 Apache/PHP, Node.js, MySQL 실행.
2. LAN PC 4대에서 초대 코드로 게스트 참여.
3. 사용자 A가 그리는 동안 나머지 PC에서 선 확인.
4. B는 도형을 이동하고, A가 같은 객체 수정을 시도하면 잠금 안내 확인.
5. C는 PNG 이미지를 등록하고 D는 허용 영상 URL을 배치.
6. 저장 완료 응답을 확인하고 모두 새로고침.
7. 완성된 작업이 그대로 표시되고, 프로젝트별 보드가 혼합되지 않는지 확인.
8. 시간 여유와 P1 완료 여부에 따라 업무 연동 시연.

**주의:** AC15 는 학교 PC 에서 [배포 가이드](15-deployment-school-pc.md)대로 확인합니다.
