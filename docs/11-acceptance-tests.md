## 보안 점검 (수용 기준과 별도)

| ID | 검증 대상 | 통과 조건 | 상태 |
|---|---|---|---|
| SEC01 | 접속 출처 제한 | 다른 사이트 출처(Origin)의 웹소켓·폴링 연결은 403. 실시간 서버와 같은 호스트에서 열린 페이지와 출처 없는 클라이언트는 허용 | 통과(자동) |

| SEC02 | 요청 제한 | 한 연결이 한꺼번에 보낸 요청 400개 중 300개만 받고 나머지는 `RATE_LIMITED` 로 거절, 잠시 뒤에는 다시 받음. 미리보기 3000개는 일부만 전달되고 그동안에도 잠금 요청은 처리 | 통과(자동) |

SEC01 은 실제 브라우저로도 확인했습니다(2026-10-08). 허용된 출처에서는 보드가 연결되고, 허용 목록에 없는 출처에서는 연결이 거부되며 화면에 안내가 뜹니다.

## 시연 리허설 (자동)

`cd apps/realtime` 에서 `npm run rehearsal` 을 실행하면 브라우저 네 개(관리자 1·편집자 3)로 [시연 대본](16-demo-script.md)의 1~10번 장면을 실제 마우스·키보드 입력으로 실행합니다. 2026-10-10 개발 PC 에서 13개 항목이 모두 통과했습니다.

| 항목 | 확인하는 것 |
|---|---|
| 점검 | 접속 점검 화면(`check.html`)의 웹 서버·실시간 서버 주소·실시간 연결·왕복 시간이 통과 |
| 1 입장 | 초대 링크·코드 입장, 참여자 4명과 역할 |
| 2 보드 열기, 커서와 선택 표시 | 네 화면의 참여자 4명, 서로의 커서. 한 사람이 고른 메모가 다른 3대에 그 사람의 이름으로 표시되고 풀면 사라짐 |
| 3 펜 | 놓기 전에 다른 3대에 미리보기, 놓은 뒤 4대에 확정 |
| 4 잠금 | 잡는 동안 3대에 잠금 표시, 다른 사람의 클릭은 안내만, 놓으면 4대에 새 위치 |
| 5 이미지와 영상 | 파일 선택으로 올린 PNG, YouTube 주소로 만든 영상 객체(재생은 확인하지 않음) |
| 6 공유 업무 | 기획 보드의 업무 패널에서 체크리스트를 체크하고 항목을 더하면, 그리고 상태를 바꾸면 개발 보드를 보고 있는 화면에 전달. 체크리스트를 바꿔도 업무 버전은 그대로 |
| 7 새로고침 후 복원 | 새로고침만으로 네 화면이 보던 보드와 위치로 돌아오고 내용이 서버 저장 내용과 일치. 작업실에서 새로고침하면 작업실에 머묾 |
| 8 실행 취소·다시 실행과 PNG | 사각형 생성·되돌리기·다시 실행이 네 화면에 전파, PNG 파일이 실제로 저장됨 |
| 9 업무 현황판 | 작업실에서 카드를 끌어 옮기고 새 업무를 만들면 보드에 있는 세 화면에 전달, 마감 임박·지남 표시, 6번에서 바꾼 상태가 현황판에 반영. 카드의 진행률(1/4)이 보이고, 카드를 눌러 연 창에서 항목을 체크하면 카드(2/4)와 보드의 세 화면에 전달 |
| 10 열람자 | 도구 비활성, 서버가 생성 요청 거부. 열람자가 진행자의 이름표를 두 번 눌러 따라가고 Esc 로 해제 |
| 지연 | 미리보기 전달·확정 저장 응답의 중앙값이 기준 이내 |
| 마무리 | 네 화면과 서버의 객체·연결선이 같고 화면 스크립트 오류 없음 |

**한계:** 네 화면이 모두 한 PC 안에서 돕니다. 다른 PC 의 접속, 방화벽, LAN 구간의 지연은 확인하지 못하므로 AC15 를 대신하지 않습니다. 이미지 드래그·붙여넣기(AC10)와 영상 재생도 여전히 사람이 확인합니다.

## 최종 시연 흐름

1. 학교 PC에서 Apache/PHP, Node.js, MySQL 실행.
2. LAN PC 4대에서 초대 코드로 게스트 참여.
3. 사용자 A가 그리는 동안 나머지 PC에서 선 확인.
4. B는 도형을 이동하고, A가 같은 객체 수정을 시도하면 잠금 안내 확인.
5. C는 PNG 이미지를 등록하고 D는 허용 영상 URL을 배치.
6. 저장 완료 응답을 확인하고 모두 새로고침.
7. 완성된 작업이 그대로 표시되고, 프로젝트별 보드가 혼합되지 않는지 확인.
8. 시간 여유와 P1 완료 여부에 따라 업무 연동 시연.

**주의:** AC15 는 학교 PC 에서 [배포 가이드](15-deployment-school-pc.md)대로 확인합니다. 사람·PC 별 진행표는 [시연 대본](16-demo-script.md)에 있습니다.
