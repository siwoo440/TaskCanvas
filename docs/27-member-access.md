# 27일차 — 회원 권한·초대·실시간 세션 연계

---
## 구현 내용

- 회원 로그인 시 본인 게스트를 복원하거나 새로 생성. 이미 유효한 미연결 게스트가 있으면 자동 연결 없이 그대로 보존.
- 내 작업실 목록·초대 코드 참여·작업실 전환·새로고침 복원. 회원은 기존 이름 기반 재입장 코드 대신 로그인과 작업실 목록으로 재입장.
- 현재 게스트를 회원 비밀번호 재확인 후 연결. 다른 회원 소유 연결 덮어쓰기 금지, 같은 회원 연결은 멱등 처리.
- 회원 연결 시 이전 게스트 세션·미사용 티켓 폐기. 연결된 이름의 게스트 재입장 차단. 업무·담당자·작성자 참조 보존.
- 관리자·편집자·열람자 서버 역할 검사 유지. 회원의 모든 연결 게스트에서 작업실을 조회하고, 같은 작업실은 최고 역할·작은 guest_id 순으로 대표 선택. 데이터 병합 없음.
- 회원용 게스트 세션은 발급 회원 세션에, 티켓은 발급 게스트 세션에 결합. 로그아웃·만료·재로그인 교체·멤버십 제거 후 접근 차단.
- Socket.IO 수신 이벤트마다 세션 검사, 유휴 연결 1000ms 주기 검사. 무효 소켓 해제 시 기존 참여자·잠금 정리 사용. DB 조회 실패도 접근 거부.

## 신규 API

| API | 응답과 권한 |
|---|---|
| GET /api/auth/workspaces | 회원 필수. projects: project_id·title·role·guest_id, can_link_guest, 현재 guest |
| POST /api/auth/guest-link | password 재확인. 현재 서버 게스트 세션만 대상. 성공 200 {guest} |
| POST /api/auth/workspaces/select | project_id. 본인 작업실만 허용. 성공 200 {guest, project_id, role}와 새 결합 게스트 쿠키 |
| POST /api/auth/workspaces/join | invite_code. 성공 201 {guest, project_id, role}. 이미 참여한 작업실은 역할 유지·추가 차감 없음 |

변경 API는 X-TaskCanvas: 1 헤더가 필요하다. 초대 가입·비밀번호 확인은 기존 IP 제한을 공유한다. 초대의 만료·폐기·한도 검사는 트랜잭션 안에서 처리한다. 동일 회원 동시 가입은 회원 행 잠금으로 직렬화한다. 연결·이전 세션 폐기·새 결합 세션 저장은 같은 트랜잭션이며 쿠키는 커밋 후에만 전송한다. 신규 세션 INSERT 실패 트리거로 전체 롤백을 검증했다.

GET /api/me의 guest·projects는 유지한다. 회원용 세션에서는 member: true와 회원 전체 작업실 목록을 추가한다. 다른 게스트의 작업실로 이동할 때 select API를 먼저 호출한다. 기존 비회원 GET /api/me 응답은 유지한다.

## DB 보정과 배포

guest_sessions.user_session_id → user_sessions.session_id, realtime_tickets.guest_session_id → guest_sessions.session_id를 NULL 허용 외래키로 추가했다. 세션 삭제 시 종속 세션·티켓은 ON DELETE CASCADE로 정리한다. 기존 독립 게스트 세션과 업무 데이터는 보존한다.

기존 DB는 전체 백업 후 `C:\xampp\php\php.exe apps/php-api/bin/migrate.php` 실행. PHP와 Node를 함께 갱신하고 실시간 서버를 재시작한다. 보정 전 티켓은 발급 세션 정보가 없으므로 새 서버에서 거부하며, 화면에서 새 티켓을 발급받는다. 토큰·비밀번호·초대 코드·업로드와 로컬 백업은 커밋하지 않는다.

로컬 개발 DB는 tmp/day27에 덤프 백업을 저장한 뒤 두 컬럼을 추가했다. 신규 설치·보정 정의 일치와 반복 실행은 별도 테스트 DB에서 확인했다.

## 남은 범위와 한계

- 유휴 소켓의 수신 차단에는 최대 감시 간격 1초와 DB 처리 시간이 필요하다. 이미 처리 중인 요청을 소급 취소하지 않는다.
- 세션을 잃은 기존 게스트는 이름·초대 코드만으로 회원에 이전할 수 없다. 소유 이전·연결 해제 API 없음.
- 역할 변경·멤버 퇴장·마지막 관리자 보호 화면은 39일차 범위. 이번에는 기존 역할 검사와 멤버십 제거 시 인증 차단을 검증했다.
- 기존 관리자 초대 표는 360px 화면에서 취소 버튼 때문에 약 17px의 가로 넘침이 남는다. 신규 회원 작업실 패널은 화면 안에서 줄바꿈된다.
- 학교 PC 4대 AC15와 AC10 추가 입력 방식은 기존 수동 검증 범위로 유지한다.
