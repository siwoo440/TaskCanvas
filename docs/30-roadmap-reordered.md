# TaskCanvas 최신 개발 일정 — 30~40일차 압축 로드맵

> **최신 기준: 2026-10-21. 상태: 30~34일차 구현 완료, 35~40일차 계획.** 1~29일차 구현 기록은 유지한다. 기존 33~78일차 계획은 수업 프로젝트의 필수 결과물을 우선하도록 33~40일차로 압축했다. 개발 일차는 달력상의 날짜나 실제 소요 기간이 아니라 검증 가능한 작업 묶음이다.

## 1. 압축 원칙

- DB 회원가입·로그인, DB 통계, 자체 대시보드, CSV·JSON 가져오기, 공공데이터 API, 보안·복구, 학교 LAN 검증은 유지한다.
- 서로 같은 데이터와 화면을 수정하는 작업은 한 일차로 합친다.
- 각 일차는 구현과 단위·권한·무결성 검증을 함께 끝낸다.
- 브라우저 내 DOCX·XLSX·PPTX 직접 편집, Google Drive OAuth, 조건 자동화, 반복 업무, 업무 의존 관계, AI 요약, 외부 문서 임베드는 후속 백로그로 이동한다.
- 오피스 파일은 직접 편집 대신 업로드·안전한 미리보기·원본 다운로드 MVP로 축소한다.
- 외부 API가 실패하면 마지막 정상 데이터와 로컬 CSV·JSON 가져오기를 사용하며 실패를 성공으로 표시하지 않는다.

## 4. 33일차 완료 결과와 다음 34일차 방향

**완료:** 기간·상태·담당자 조건을 KPI·차트·표·CSV에 동일하게 적용하고, 실제 상태 변경 이력으로 추이를 계산하며 차트에서 원본 업무까지 이동한다. 데이터셋은 업무 원본과 관계 키가 없어 업무 통계에 섞지 않고 별도 데이터 관리 화면에 유지한다.

### 데이터와 API

- 업무 상태 변경마다 업무 ID, 변경 전·후 상태, 행위자, 실제 변경 시각을 한 번만 기록한다.
- 과거에 기록되지 않은 완료 시각은 생성일이나 현재 상태로 추정하지 않는다.
- 기존 작업실·기간·상태·담당자 필터를 대시보드·상세·CSV가 함께 사용한다.
- 대시보드 JSON, 상세 목록, CSV가 하나의 정규화된 필터 계약을 사용한다.
- 차트 구간 선택값은 서버에서 다시 검증하며 작업실 권한 검사를 우회하지 않는다.

### 화면

- 필터 적용 시 KPI·도넛·막대·추이·표를 한 요청 결과로 갱신한다.
- 상태 또는 담당자 차트 선택 시 같은 조건의 상세 업무를 표시한다.
- 상세 업무에서 원본 보드로 이동하되 접근 불가·삭제된 보드는 명확히 안내한다.
- CSV 내보내기는 현재 적용된 필터를 사용하며 UTF-8 BOM으로 한글 호환성을 확보한다.

### 완료 기준

- 같은 필터의 KPI 총계, 차트 합계, 표 전체 건수, CSV 행 수가 일치한다.
- 상태 변경 한 건당 이력 한 건만 저장되고 재시도 시 중복되지 않는다.
- 기록 이전 기간은 기록된 전환 0건으로 표시하고 과거 이력을 추정하지 않는다는 안내를 제공한다.
- 다른 작업실의 이력·업무·CSV에 접근할 수 없다.
- 빈 결과, 역순 기간, 삭제된 담당자, 삭제된 보드, 네트워크 실패를 처리한다.
- 기존 28~32일차 통계·대시보드·가져오기 회귀 검사를 통과한다.

### 34일차 완료와 다음 35일차

- 34일차에 회원별 저장 뷰·개인 홈·통합 검색·역할 관리·키보드 기본 흐름을 구현하고 권한·동시 강등·늦은 응답을 검증했다. [상세 결과](34-member-workflow.md).
- 35일차는 실제 행위자·전후 값·시각 기반 전체 활동 기록을 먼저 정의한다.
- 템플릿은 원본 권한·초대·회원 개인 설정을 복제하지 않는다.
- 알림은 배정·마감·중요 변경의 수신자·읽음 상태와 중복 방지를 구현한다.
