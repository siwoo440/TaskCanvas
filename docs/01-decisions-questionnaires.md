## 충돌·범위 조정

- **회원가입 → 게스트:** 초기 문서의 일반 계정/로그인 요구는 4차 결정에 따라 MVP에서 제외.
- **펜 실행 취소:** 2차 기능에 있었으나 3차에서 제외.
- **동영상 업로드:** 직접 업로드가 아니라 외부 URL 임베드로 확정.
- **파일 업로드:** 4차에서는 이미지 3형식만 10MB 이하로 제한. 일반 PDF·문서 업로드는 MVP 제외.
- **고급 표:** 후속 개발(P2).
- **업무 완전 연동:** 최종 목표지만 P0 실패 위험을 줄이기 위해 첫 3주에는 P1. P0 완료 시 구현.
- **모든 객체·정렬:** 다양한 객체의 전체 요구는 보존하되 P0/P1/P2로 분리.
- **학교 PC 설치·방화벽:** Node.js 기술 허용과 별개로 실제 학교 PC 실행 권한은 미확인.

## 구현 후 달라진 점 (16단계 기준)

위 표는 질문 당시의 답변 기록이라 고치지 않았습니다. 구현하면서 달라진 것만 적습니다.

- **펜 실행 취소:** 3차에서 제외했지만, 12·16단계에서 펜을 포함한 모든 객체 작업의 실행 취소와 다시 실행으로 구현했습니다.
- **텍스트·메모:** 확장 대상이었으나 11단계에서 구현했고 16단계에서 글자 크기 조절을 더했습니다.
- **초대:** 모의 이메일 초대는 만들지 않았습니다. 초대 링크와 관리자 화면의 발급·취소·인원 제한으로 대신합니다.
- **반영 지연:** 숫자 목표가 없었으나 14단계에서 측정 방법과 기준(제안값)을 정했습니다. [미정 사항](14-open-decisions.md) 참고.
- **첫 화면:** 입장하면 기본 보드가 바로 열리는 대신, 작업실에서 보드를 고릅니다.
