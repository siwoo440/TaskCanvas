# TaskCanvas 발표 PPT

## 발표에 쓰는 자료

- **TaskCanvas_팀프로젝트_발표자료_14장.pptx**: 4차 결정(게스트 입장·이미지 10MB·학교 PC LAN)과 구현 결과를 반영한 최신본. 4·9·10·11장은 실제 화면 캡처, 13장은 수용 테스트 결과, 14장은 위험과 대응입니다. 글과 도형은 PowerPoint 에서 바로 고칠 수 있고 모든 장에 발표자 노트가 있습니다.
- **TaskCanvas_14장_미리보기.jpg**: 14장 썸네일 미리보기.

발표 전에 8~11장의 A·B·C·D 를 실제 이름으로 바꾸고, 학교 PC 리허설 뒤 13장의 AC15(미실행) 표시를 결과에 맞게 고칩니다. 구성과 손볼 곳은 [발표 자료 관리](../docs/13-presentation-plan.md), 진행 순서는 [시연 대본](../docs/16-demo-script.md)을 참고합니다.
