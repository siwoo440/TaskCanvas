# 데이터베이스 스키마

- `schema.sql`은 기존 화이트보드·업무 데이터와 25일차 회원 데이터 기반을 포함한 신규 설치용 스키마입니다.
- 기존 설치는 백업 후 `apps/php-api/bin/migrate.php`로 누락된 테이블·컬럼을 보정합니다. 기존 데이터는 보존하며 반복 실행할 수 있습니다.
- 회원 데이터는 `users`, `user_sessions`, `guest_user_links` 세 테이블입니다. 실제 회원가입·로그인·게스트 연결 API는 26~27일차 예정입니다.
- PHP 8.2.12 / MariaDB 10.4.32에서 신규 설치·보정·외래키·중복 제약·기존 데이터 보존을 검증했습니다. **학교 PC의 실제 버전 호환성**은 별도 확인이 필요합니다.
- 실제 배포 DB 계정과 암호, 프로젝트 초대 코드는 저장소에 기록하지 않음.
- 전환 시나리오와 검증 명령은 [25일차 회원 데이터](../docs/25-member-data.md)를 참고합니다.
