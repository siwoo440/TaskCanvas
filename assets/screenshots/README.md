## 다시 찍기

화면을 고친 뒤에는 아래 명령으로 9장을 한 번에 다시 만듭니다. MariaDB 만 켜져 있으면 됩니다.

```bash
cd apps/realtime
```

```bash
npm run capture
```

- 임시 서버(PHP 8082·실시간 3003)를 띄우고 "시연 프로젝트"를 새로 만들어 예시 내용을 채운 뒤, 관리자와 편집자 두 사람으로 접속해 찍습니다. 실행 중인 개발 서버(8080·3001)는 건드리지 않습니다.
- 찍는 김에 초대 링크 입장, 업무 현황판의 카드 끌기, 카드 수정과 충돌 처리, 메모 글 입력·저장, 글자 크기 변경, Ctrl+Z 되돌리기, Ctrl+Y 다시 실행을 실제 키보드·마우스 입력으로 확인하고 결과를 출력합니다.
- 실행할 때마다 `.env` 의 DB 에 "시연 프로젝트"가 하나씩 생깁니다(다른 DB 를 쓰려면 `DB_NAME` 환경 변수). 시연 전에는 `scripts\reset-demo.bat` 으로 정리합니다.
- 캡처에 쓰인 초대 코드는 화면에 찍히지 않습니다(입장 화면은 자리 표시 문자열, 관리 화면은 역할·만료일만 표시).

발표 자료의 그림은 자동으로 바뀌지 않습니다. 다시 찍었다면 PowerPoint 에서 그림을 선택하고 **그림 바꾸기**로 교체합니다.
