# Frontend

프레임워크·빌드 도구 없이 HTML/CSS/JavaScript 와 Canvas API 로 만든 화이트보드 화면입니다. `public/` 폴더를 그대로 웹 서버에 올리면 동작합니다. 화면 구성은 [docs/04-ui-spec.md](../../docs/04-ui-spec.md), 이벤트는 [docs/08-realtime-contract.md](../../docs/08-realtime-contract.md)를 따릅니다.

## 폴더 구조

```
frontend/public/
├── index.html        # 홈(소개 ↔ 작업실) / 작업실 만들기 / 입장 / 화이트보드 화면
├── check.html        # 접속 점검(입장 없이 이 PC 에서 서버에 닿는지 확인)
├── css/app.css
├── css/check.css     # 접속 점검 화면 스타일
└── js/
    ├── config.js     # API 경로, 실시간 서버 주소(기본: 같은 호스트의 3001 포트)
    ├── api.js        # fetch 래퍼 (JSON, X-TaskCanvas 헤더, 오류 코드)
    ├── realtime.js   # Socket.IO 연결, 티켓으로 보드 참여 또는 작업실 연결, 재접속 시 자동 재참여
    ├── media.js      # 이미지 업로드(multipart), 영상 URL 사전 검사, 영상 iframe 오버레이
    ├── carousel.js   # 소개 페이지의 기능 카드 넘겨 보기(좌우 화살표·아래 점·방향키, 가로 스크롤 스냅)
    ├── taskboard.js  # 작업실의 업무 현황판(상태별 세 열, 카드 끌기), 마감 표시 계산(보드의 업무 블럭도 함께 씀)
    ├── canvas.js     # 격자·객체·미리보기·커서·선택/잠금 표시 렌더링, 클릭 판정, 확대·이동 뷰포트
    ├── tools.js      # 선택·크기 조절·연결선·펜·사각형·원·이동 도구 입력 처리, 단축키
    ├── check.js      # 접속 점검 화면 동작(웹 서버·실시간 연결·왕복 시간·외부 영상)
    └── app.js        # 화면 전환, 상태, API·실시간 연결, 잠금 기반 이동·크기 조절·삭제·속성 변경, 업무·연결선·초대 관리
```

Socket.IO 클라이언트 스크립트는 실시간 서버가 제공하는 `http://<서버>:3001/socket.io/socket.io.js` 를 동적으로 불러오므로 인터넷 연결이 없는 학교 LAN 에서도 동작합니다.

## 개발 실행 (서버 1대)

MariaDB 가 실행 중이고 `apps/php-api/.env`, `apps/realtime/.env` 가 준비된 상태에서:

```bash
C:/xampp/php/php.exe -S 0.0.0.0:8080 -t apps/frontend/public apps/php-api/public/index.php
```

```bash
node apps/realtime/src/server.js
```

브라우저에서 `http://localhost:8080` 을 열고 초대 코드로 입장합니다. 다른 PC 는 `http://<서버 LAN IP>:8080` 으로 접속하며, 실시간 서버는 같은 호스트의 3001 포트로 자동 연결됩니다. (PHP 내장 서버는 `/api/*` 만 PHP 로 처리하고 나머지는 이 폴더의 정적 파일을 제공합니다.)

## Apache(XAMPP) 배포

1. `apps/frontend/public` 내용을 `C:/xampp/htdocs/` 에 복사(또는 `DocumentRoot` 변경).
2. `apps/php-api/README.md` 의 `Alias /api` 설정 추가.
3. `js/config.js` 의 `realtimeUrl` 이 서버 PC 주소와 맞는지 확인(기본값은 접속한 호스트의 3001 포트).

## 화면 동작

| 화면 | 동작 |
|---|---|
| 홈 — 소개 | 처음 열면 보이는 소개 페이지(기능·시작 방법·역할 안내). "TaskCanvas 로 할 수 있는 일"은 그림이 들어간 카드 6장을 한 장씩 넘겨 보는 형식이며 좌우 화살표, 아래 점, 방향키, 터치 밀기로 넘기고 마지막에서 다음을 누르면 처음으로 돌아감. "새 작업실 만들기" 는 만들기 화면으로, "초대 코드로 입장"·"입장하기" 는 입장 화면으로 이동. `GET /api/me` 로 세션을 확인해 입장한 상태면 소개 대신 작업실로 구성됨 |
| 작업실 만들기 | 이름·작업실 이름 → `POST /api/projects`. 초대 코드 없이 내 작업실이 첫 보드와 함께 만들어지고 관리자로 바로 들어감. 작업실 맨 위에 재입장용 **내 코드**가 한 번 표시됨(복사 버튼, "보관했습니다"를 누르거나 나가면 사라짐. 브라우저에 저장하지 않음) |
| 입장 | 이름·초대 코드 → `POST /api/guest/join`. 초대 링크(`…/#code=코드`)로 열면 소개를 건너뛰고 코드가 자동 입력되며 주소창에서는 바로 지워짐 |
| 홈 — 작업실 | 입장하면 같은 홈 화면이 작업실로 바뀜. 상단에 이름·역할·나가기, 본문에 작업실 이름(관리자는 **이름 변경**), 보드 카드(생성·이름 변경은 편집자 이상, 삭제는 관리자만이며 확인 대화상자를 거침), **업무 현황판**(공유 업무를 할 일·진행 중·완료 세 열로 표시. 편집자 이상은 카드를 끌어 다른 열에 놓아 상태를 바꾸고, 카드를 눌러 제목·담당자·마감일을 고치고, **새 업무**로 만듦. 작업실용 티켓으로 실시간 서버에 연결되어 보드의 업무 블럭과 서로 바로 반영되고, 오른쪽 위에 연결 상태가 보임. 마감이 지났거나 3일 안이면 카드에 색 표시), 참여자 목록. 관리자에게는 **초대 코드 관리**(역할·유효 기간을 골라 발급, 코드·링크 복사, 목록·취소)가 표시됨. 나가면 다시 소개 페이지로 돌아감 |
| 화이트보드 | 스냅샷 복원 → 티켓 발급 → `board:join`. 상단에 보드 전환·참여자·연결/저장 상태 |

| 조작 | 동작 |
|---|---|
| 선택 (V) | 객체 클릭 → `object:lock` 획득 후 드래그 이동(`object:preview`), 놓으면 `object:commit`. Shift+클릭으로 선택 토글, 빈 곳 드래그는 영역 선택. 여러 개를 선택하고 끌면 모든 객체 잠금을 얻은 뒤 함께 이동(하나라도 타인 잠금이면 전체 취소) |
| 연결선 (L) | 객체에서 객체로 드래그 → `link:create`. 선을 클릭하면 오른쪽 패널에서 라벨 저장(`link:update`)·삭제(`link:delete`). 연결된 객체를 지우면 선도 사라짐 |
| 모서리 핸들 | 도형·이미지·영상·업무 블럭을 하나만 선택하면 네 모서리에 핸들 표시. 끌면 반대편 모서리를 고정한 채 크기 조절(`object:preview{x,y,width,height}` → `object:commit`). 이미지·영상은 항상 비율 유지, 그 외는 Shift 로 비율 유지, 최소 10 단위 |
| Delete / Backspace | 선택 객체(여러 개 가능)를 하나씩 잠근 뒤 `object:delete`, 연결선 선택 시 `link:delete` |
| 실행 취소 (Ctrl+Z, 상단 ↶ 버튼) | 이 보드에서 내가 한 마지막 작업부터 되돌림: 생성(펜·도형·메모·이미지·영상·업무 블럭)·이동·크기·스타일·메모 글·삭제·연결선(생성·라벨·삭제). 함께 옮기거나 함께 지운 것은 한 번에 되돌림 |
| 다시 실행 (Ctrl+Y·Ctrl+Shift+Z, 상단 ↷ 버튼) | 방금 되돌린 작업을 다시 적용. 새 작업을 하면 다시 실행할 기록은 비워짐 |
| 복제 (Ctrl+D) | 선택한 객체를 오른쪽 아래로 20 옮겨 같은 내용으로 하나 더 만들고 사본을 선택. 연결선은 복제하지 않음 |
| PNG 내보내기 (상단 ⬇ PNG) | 모든 객체가 들어가는 범위를 흰 배경의 PNG 로 저장(격자·커서·선택 표시 제외, 긴 변 최대 4096px). 영상은 자리 표시만 그려짐 |
| 속성 패널 변경 | 선택 객체가 있으면 잠근 뒤 `object:commit{changes:{style}}` 로 색상·굵기·채우기 적용. 메모·텍스트는 글자 크기(12·16·20·28·40)도 바꾸며, 글이 넘치면 높이를 함께 늘림 |
| 펜 (P) | 누른 채 이동하면 약 40ms 단위로 `stroke:preview`, 놓으면 `stroke:commit` |
| 사각형 (R) / 원 (O) | 드래그로 생성, 놓으면 `object:create` |
| 메모 (N) / 텍스트 (X) | 클릭(기본 크기)하거나 끌어서 놓으면 `object:create{type:'note'}` 후 바로 글 입력. 메모는 노란 배경(채우기 색을 켰으면 그 색), 텍스트는 배경 없음. 더블클릭해 글 수정 — 바깥 클릭·Ctrl+Enter 저장(`object:commit{changes:{text}}`), Esc 취소. 글이 넘치면 높이를 자동으로 늘리고, 방금 만든 메모를 비워 두면 삭제 |
| 이미지 🖼 | 파일 선택·캔버스에 드래그 앤 드롭·Ctrl+V → `POST /api/images` → `object:create{type:'image'}`. 긴 변 400 단위로 맞춰 삽입 |
| 영상 ▶ | URL 입력(YouTube·Vimeo) → `object:create{type:'video'}`. 서버가 만든 `embed_url` 을 오버레이 iframe 으로 표시, 제목 막대를 잡아 이동 |
| 업무 블럭 ☑ (T) | 기존 업무 선택 또는 새 업무 생성(`task:create`) → `object:create{type:'task', payload:{task_id}}`. 블럭을 선택하면 오른쪽 패널에서 제목·상태·담당자·마감일을 수정(`task:update`)하며 같은 업무를 참조하는 모든 보드의 블럭이 함께 바뀜. 블럭 삭제는 보드 표시만 제거 |
| 업무 블럭의 마감 표시 | 마감이 지났으면 블럭 오른쪽 위에 빨간 `n일 지남`, 오늘이거나 3일 안이면 주황 `오늘 마감`·`D-n`. 완료한 업무와 마감이 먼 업무에는 붙지 않음(작업실 현황판과 같은 기준, 이 PC 의 날짜로 계산) |
| 격자 맞춤 | 속성 패널 체크 시 도형 생성·이동 좌표를 10 단위로 맞춤 |
| 이동 (H), Space+드래그, 가운데 버튼 | 화면 이동 |
| 마우스 휠 | 커서 기준 확대·축소 (0.1~8배) |
| ⤢ | 객체 전체가 보이도록 화면 맞춤 |
| Esc | 그리는 중인 획·도형 취소, 이동 취소(잠금 해제), 선택 해제 |

- 저장 상태는 서버 ack(`persisted:true`)를 받은 뒤에만 `저장됨` 으로 바뀝니다. 응답 대기 중인 객체는 반투명으로 표시되고, 실패하면 화면에서 제거되고 안내가 뜹니다.
- 연결이 끊기면 `재접속 중` 으로 표시되고, 다시 연결되면 새 티켓으로 자동 재참여한 뒤 **서버의 마지막 저장 상태**를 다시 불러옵니다(미저장 작업은 복구하지 않음).
- 보드를 열었는데 실시간 서버에 한 번도 연결되지 못하면(서버 꺼짐·포트 차단·접속 출처 불허) 접속 점검 화면을 열어 보라는 안내가 한 번 뜹니다.
- 보드를 보다가 새로고침하면 작업실을 거치지 않고 그 보드로, 보던 위치·배율 그대로 돌아옵니다. 탭마다 `sessionStorage` 에 보드 번호와 화면 위치만 적어 두고, 작업실로 나오거나 나가기를 누르면 지웁니다. 그 사이 보드가 삭제되었으면 작업실이 열립니다.
- 열람자는 도구가 비활성화되고 화면 이동만 가능합니다. 서버도 별도로 권한을 검사합니다.
- 타인의 커서는 5초, 확정되지 않은 미리보기는 15초 뒤 자동으로 지워집니다.
- 다른 사용자가 잠근 객체는 그 사람 색상의 점선 테두리와 "OOO 편집 중" 이름표로 표시되고, 클릭하면 안내만 뜨고 선택되지 않습니다. 타인의 이동 중 위치(`object:preview`)도 실시간으로 따라갑니다.
- 이동 중 잠금이 만료되거나(30초) 다른 사용자가 먼저 수정해 `VERSION_CONFLICT` 가 나면 이동을 취소하고 스냅샷을 다시 불러옵니다.

- 이미지는 `<img>` 캐시로 캔버스에 직접 그리고(로딩·실패 자리 표시 포함), 영상은 캔버스에 그릴 수 없으므로 `#overlay` 의 iframe 을 매 렌더마다 캔버스 좌표에 맞춰 이동·크기 조정합니다. iframe 영역은 재생용으로 클릭을 받고, 위쪽 제목 막대만 캔버스가 받아 선택·이동합니다.

- 보드 화면은 창 높이에 고정되고 도구 막대·속성 패널만 내부에서 스크롤됩니다(낮은 화면에서도 캔버스가 밀리지 않음). `hidden` 속성은 전역 규칙(`[hidden]{display:none!important}`)으로 항상 숨김 처리합니다.
- 초대 코드 복사는 HTTPS·localhost 에서는 Clipboard API, LAN 의 http 접속에서는 `execCommand('copy')` 대체 방식을 씁니다.

- 메모 글 입력은 캔버스 위에 같은 위치·크기·글꼴의 `<textarea>` 를 겹쳐서 받습니다. 편집 중에는 선점 잠금을 유지하고(10초마다 연장), 캔버스 영역은 `overflow: clip` 이라 화면 밖에 걸친 메모를 편집해도 밀리지 않습니다.
- 하나만 선택하면 속성 패널이 그 객체의 색·굵기·채우기로 맞춰집니다. 그래서 한 항목만 바꿔도 나머지 스타일이 유지됩니다.
- 열려 있는 보드의 이름이 작업실에서 바뀌면 상단 보드 이름이 갱신되고, 보드가 삭제되면 안내와 함께 작업실로 돌아갑니다(`board:renamed`/`board:deleted`).
- 같은 객체를 연달아 잠그는 동작(더블클릭, 저장 직후 드래그)은 앞선 잠금 요청·확정이 끝난 뒤에 다음 잠금을 보내 서버 도착 순서를 보장합니다.

- 실행 취소는 서버에 새 기능을 두지 않고 기존 이벤트로 구현했습니다. 클라이언트가 작업마다 "되돌릴 때 다시 보낼 값"을 최대 50개까지 기억했다가, 이전 값으로 `object:commit` 을 보내거나(수정), `object:delete` 를 보내거나(생성), 같은 내용으로 다시 만듭니다(삭제 — 새 ID 가 되므로 예전 ID 와의 대응을 기억해 그 앞의 기록도 계속 되돌릴 수 있음).
- 여러 사람이 쓰는 보드라 **내 작업 뒤에 다른 사람이 손댄 객체는 되돌리지 않습니다.** 내가 만들거나 바꾼 직후의 버전을 기억해 두고, 지금 버전이 다르거나 누가 잡고 있으면 그 기록은 버리고 안내만 합니다. 기록은 보드를 바꾸거나 재접속하면 비워집니다.
- 다시 실행은 되돌릴 때마다 그 반대 작업을 따로 쌓아 두었다가 같은 방식으로 적용합니다. 지운 객체를 되살리면 새 ID 가 되므로, 예전 ID 와의 대응을 따라가 그 뒤의 기록도 이어서 적용합니다. 다른 사람이 이후에 고친 객체를 건드리지 않는 규칙은 실행 취소와 같습니다.
- 메모의 글자 크기는 `style.size`(보드 좌표 단위)이고 줄 높이는 그에 비례합니다. 예전에 만든 메모처럼 값이 없으면 16 으로 그립니다.
- 도구 단축키(V·P·R 등)는 Ctrl·Alt 와 함께 누르면 반응하지 않습니다(Ctrl+V 붙여넣기가 선택 도구로 바뀌던 문제 수정).

## 접속 점검 화면

`http://<서버>:8080/check.html` 은 시연 전에 각 접속 PC 의 브라우저에서 여는 화면입니다. 입장하지 않아도 열리고 서버에 아무것도 저장하지 않습니다.

| 항목 | 확인하는 것 |
|---|---|
| 브라우저 | Chrome·Edge 인지, 쿠키가 켜져 있는지, 창이 너무 좁지 않은지 |
| 웹 서버 | `/api/health` 응답과 DB 연결, 응답 시간 |
| 실시간 서버 주소 | 3001 포트에서 Socket.IO 파일을 받을 수 있는지(서버 꺼짐·방화벽) |
| 실시간 연결 | 웹소켓으로 연결되는지. 폴링으로만 되면 주의, 거부되면 접속 출처 설정 안내 |
| 왕복 시간 | `net:ping` 10번의 중앙값. 150ms 를 넘으면 주의 |
| 외부 영상 | YouTube 임베드 주소에 닿는지. 안 되면 영상 장면을 건너뛰라는 주의 |

`localhost` 로 열면 웹 서버 응답이 요청마다 0.2초쯤 느리게 나옵니다(이름 풀이 때문). 다른 PC 와 같은 조건으로 보려면 서버 IP 주소로 엽니다.
