실시간 협업 화이트보드 · 웹서버 수업 팀 프로젝트

같은 보드에서 함께 그리고,
업무까지 한눈에 정리합니다

내 작업실을 직접 만들거나 초대 코드로 입장해 여러 명이 같은 화이트보드를 동시에 편집합니다. 펜·도형·메모·이미지·영상을 올리고, 업무 블럭과 연결선으로 프로젝트 흐름을 정리하세요.

회원가입은 없습니다. 이름만 정하면 내 작업실이 바로 만들어지고, 초대를 받았다면 이름과 초대 코드로 입장합니다.

    • 자동 저장
    • 새로고침 복원

시작하는 방법

  1. 작업실 만들기 또는 초대받기이름과 작업실 이름만 정해 내 작업실을 직접 만들거나, 관리자가 발급한 초대 코드·링크를 받습니다.
  2. 이름 입력 후 입장만든 사람은 관리자로 바로 들어가고, 초대받은 사람은 표시 이름과 초대 코드를 입력합니다. 회원가입은 없습니다.
  3. 작업실에서 보드 열기입장하면 이 페이지가 작업실로 바뀝니다. 보드를 골라 함께 작업하세요.

역할

  • 관리자 작업실을 만든 사람입니다. 초대 코드를 발급·취소하고 모든 편집을 할 수 있습니다.
  • 편집자 보드를 만들고 그리기·이동·삭제·업로드를 할 수 있습니다.
  • 열람자 보드를 볼 수만 있습니다.

        연결 끊김 대기
        이미지를 놓으면 업로드됩니다 (PNG·JPG·WEBP, 10MB 이하)

        속성

        공유 업무

        같은 업무를 참조하는 다른 보드의 블럭에도 함께 반영됩니다. 블럭을 지워도 업무 원본은 남습니다.

        연결선

        V: 선택 후 드래그로 이동, 속성 변경 시 적용
        N: 메모, X: 텍스트 — 더블클릭해 글 수정 (바깥 클릭·Ctrl+Enter 저장, Esc 취소)
        모서리 핸들: 크기 조절 (이미지·영상은 비율 유지, Shift: 비율 유지)
        Shift+클릭 / 빈 곳 드래그: 다중 선택 후 함께 이동
        L: 연결선 (객체에서 객체로 드래그, 라벨은 오른쪽 패널)
        Delete: 선택 객체 삭제
        Ctrl+Z: 실행 취소, Ctrl+Y: 다시 실행, Ctrl+D: 복제
        이미지: 🖼 버튼, 파일 드래그, Ctrl+V
        영상: ▶ 버튼에 URL 입력, 제목 막대를 잡아 이동
        T: 업무 블럭 추가 (여러 보드에서 같은 업무 공유)
        마우스 휠: 확대·축소
        Space+드래그: 화면 이동
        Esc: 취소·선택 해제
