# 구현 담당 작업 공간

> 단계별로 구현 중입니다. 현재 `php-api/` 의 1단계(게스트 입장·세션·보드·스냅샷·실시간 티켓), `realtime/` 의 2단계(보드 참여·커서·펜 미리보기·펜·도형 확정 저장), `frontend/` 의 3단계(입장·보드 선택·화이트보드 펜/도형/커서/복원), 4단계(선택·이동·삭제·속성 변경과 선점 잠금·버전 충돌 처리), 5단계(이미지 업로드·드래그·붙여넣기, YouTube/Vimeo 영상 임베드)가 동작합니다. 6단계에서 수용 테스트 자동 러너(`apps/realtime/scripts/acceptance.js`)와 학교 PC 배포 가이드(`docs/15-deployment-school-pc.md`)를 추가했고, 7단계(P1)에서 여러 보드가 같은 원본을 공유하는 업무 블럭과 격자 맞춤, 8단계(P1)에서 관계 연결선과 다중 선택·동시 이동을 구현해 AC16~AC19 까지 통과했습니다. 실행 방법은 각 폴더의 README 를 참고합니다.

| 폴더 | 담당 | 최초 기능 |
|---|---|---|
| `frontend/` | B | 캔버스·도형·펜·이미지/영상 UI |
| `php-api/` | D | 게스트·초대 코드·보드·파일 업로드 |
| `realtime/` | C | Socket.IO 방, 실시간 이벤트, 잠금·저장 |

A 담당은 이 세 영역을 통합·테스트하고 문서·PPT를 관리합니다.
