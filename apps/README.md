# 구현 담당 작업 공간

> 단계별 구현 기록입니다. `php-api/` 의 1단계(게스트 입장·세션·보드·스냅샷·실시간 티켓), `realtime/` 의 2단계(보드 참여·커서·펜 미리보기·펜·도형 확정 저장), `frontend/` 의 3단계(입장·보드 선택·화이트보드 펜/도형/커서/복원), 4단계(선택·이동·삭제·속성 변경과 선점 잠금·버전 충돌 처리), 5단계(이미지 업로드·드래그·붙여넣기, YouTube/Vimeo 영상 임베드)가 동작합니다. 6단계에서 수용 테스트 자동 러너(`apps/realtime/scripts/acceptance.js`)와 학교 PC 배포 가이드(`docs/15-deployment-school-pc.md`)를 추가했고, 7단계(P1)에서 여러 보드가 같은 원본을 공유하는 업무 블럭과 격자 맞춤, 8단계(P1)에서 관계 연결선과 다중 선택·동시 이동, 9단계에서 관리자 초대 코드 관리·초대 링크·크기 조절 핸들·시연 초기화 스크립트를 구현해 AC16~AC21 까지 통과했습니다. 이후 첫 화면을 소개 홈페이지로 바꾸고, 입장하면 같은 홈이 작업실(보드·참여자·공유 업무·초대 관리)로 구성되게 했습니다. 11단계에서 메모·텍스트 객체와 보드 이름 변경·삭제를 추가해 AC22·AC23 까지 통과했고, 12단계에서 실행 취소(Ctrl+Z)·복제(Ctrl+D)·PNG 내보내기를 추가했습니다. 13단계는 발표·시연 준비로, 시연용 예시 보드를 채우는 스크립트(`php-api/bin/seed-demo.php`)와 실제 화면을 찍는 스크립트(`realtime/scripts/capture-screens.js`)를 추가했습니다. 14단계는 시연 안정화로, 브라우저 네 개로 시연 대본을 돌려 보는 리허설 스크립트(`realtime/scripts/rehearsal.js`), 학교 PC 사전 점검(`scripts/check-env.bat`), 실시간 서버의 접속 출처 제한을 추가했습니다. 15단계에서는 새로고침해도 보던 보드로 돌아오게 하고, 접속 PC 가 브라우저로 여는 접속 점검 화면(`frontend/public/check.html`)을 추가했습니다. 16단계에서는 다시 실행(Ctrl+Y), 메모 글자 크기, 초대 코드 인원 제한, 쓰지 않는 업로드 파일 정리를 추가하고 기획 문서를 구현 기준으로 갱신했습니다. 17단계에서는 작업실에 업무 현황판(상태별 세 열, 카드를 끌어 상태 변경)과 마감 표시를 추가하고, 작업실도 실시간 서버에 연결되게 해 AC26 까지 통과했습니다. 18단계에서는 초대 코드 없이 소개 화면에서 작업실을 직접 만드는 기능(만든 사람이 관리자, 재입장 전용 코드, 작업실 이름 변경)을 추가하고, 낮은 권한의 코드로 높은 권한 참여자의 이름을 쓰는 입장을 막아 AC27 까지 통과했습니다. 19단계에서는 상단의 참여자 이름표를 눌러 그 사람을 따라가는 기능(AC28)과 연결마다 실시간 요청 수를 제한하는 기능(SEC02)을 추가했습니다. 20단계에서는 다른 참여자의 커서를 멈춰도 흐리게 남기고, 고른 객체·연결선을 그 사람의 색과 이름으로 표시하는 기능(AC29)을 추가했습니다. 21단계에서는 업무마다 세부 항목을 두는 체크리스트(AC30)와 예전 DB 에 표를 더하는 스키마 보정을 추가하고, 업무 여러 개를 동시에 고칠 때 실시간 서버가 멈추던 문제를 고쳤습니다. 실행 방법은 각 폴더의 README 를 참고합니다.

| 폴더 | 담당 | 최초 기능 |
|---|---|---|
| `frontend/` | B | 캔버스·도형·펜·이미지/영상 UI |
| `php-api/` | D | 게스트·초대 코드·보드·파일 업로드 |
| `realtime/` | C | Socket.IO 방, 실시간 이벤트, 잠금·저장 |

A 담당은 이 세 영역을 통합·테스트하고 문서·PPT를 관리합니다.
