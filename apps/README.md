# 구현 담당 작업 공간

> 단계별로 구현 중입니다. 현재 `php-api/` 의 1단계(게스트 입장·세션·보드·스냅샷·실시간 티켓)와 `realtime/` 의 2단계(보드 참여·커서·펜 미리보기·펜 확정 저장)가 동작하며, `frontend/` 는 아직 디렉터리만 있습니다. 실행 방법은 각 폴더의 README 를 참고합니다.

| 폴더 | 담당 | 최초 기능 |
|---|---|---|
| `frontend/` | B | 캔버스·도형·펜·이미지/영상 UI |
| `php-api/` | D | 게스트·초대 코드·보드·파일 업로드 |
| `realtime/` | C | Socket.IO 방, 실시간 이벤트, 잠금·저장 |

A 담당은 이 세 영역을 통합·테스트하고 문서·PPT를 관리합니다.
