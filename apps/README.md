# 구현 담당 작업 공간

> 단계별 구현 기록입니다. `php-api/` 의 1단계(게스트 입장·세션·보드·스냅샷·실시간 티켓), `realtime/` 의 2단계(보드 참여·커서·펜 미리보기·펜·도형 확정 저장), `frontend/` 의 3단계(입장·보드 선택·화이트보드 펜/도형/커서/복원), 4단계(선택·이동·삭제·속성 변경과 선점 잠금·버전 충돌 처리), 5단계(이미지 업로드·드래그·붙여넣기, YouTube/Vimeo 영상 임베드)가 동작합니다. 6단계에서 수용 테스트 자동 러너(`apps/realtime/scripts/acceptance.js`)와 학교 PC 배포 가이드(`docs/15-deployment-school-pc.md`)를 추가했고, 7단계(P1)에서 여러 보드가 같은 원본을 공유하는 업무 블럭과 격자 맞춤, 8단계(P1)에서 관계 연결선과 다중 선택·동시 이동, 9단계에서 관리자 초대 코드 관리·초대 링크·크기 조절 핸들·시연 초기화 스크립트를 구현해 AC16~AC21 까지 통과했습니다. 이후 첫 화면을 소개 홈페이지로 바꾸고, 입장하면 같은 홈이 작업실(보드·참여자·공유 업무·초대 관리)로 구성되게 했습니다. 11단계에서 메모·텍스트 객체와 보드 이름 변경·삭제를 추가해 AC22·AC23 까지 통과했고, 12단계에서 실행 취소(Ctrl+Z)·복제(Ctrl+D)·PNG 내보내기를 추가했습니다. 13단계는 발표·시연 준비로, 시연용 예시 보드를 채우는 스크립트(`php-api/bin/seed-demo.php`)와 실제 화면을 찍는 스크립트(`realtime/scripts/capture-screens.js`)를 추가했습니다. 14단계는 시연 안정화로, 브라우저 네 개로 시연 대본을 돌려 보는 리허설 스크립트(`realtime/scripts/rehearsal.js`), 학교 PC 사전 점검(`scripts/check-env.bat`), 실시간 서버의 접속 출처 제한을 추가했습니다. 실행 방법은 각 폴더의 README 를 참고합니다.

| 폴더 | 담당 | 최초 기능 |
|---|---|---|
| `frontend/` | B | 캔버스·도형·펜·이미지/영상 UI |
| `php-api/` | D | 게스트·초대 코드·보드·파일 업로드 |
| `realtime/` | C | Socket.IO 방, 실시간 이벤트, 잠금·저장 |

A 담당은 이 세 영역을 통합·테스트하고 문서·PPT를 관리합니다.
